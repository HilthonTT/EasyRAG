# Firmware releases

Instrument firmware is released quarterly. Security fixes can ship at any time as a patch
release.

## Staged rollout

Each release goes out in three stages over ten days: 5% of the fleet first, then 25%, then
everyone. The release manager pauses the rollout if the error rate of updated devices rises.

## Freeze

There are no releases during the first two weeks of December, when many customers do their
year-end maintenance.

## Rollback

If a release causes problems, the release manager must be able to roll it back within one hour.
The release manager role rotates between firmware engineers each quarter.

# Security rules

## Passwords and accounts

Passwords must be at least 14 characters long. Store them in Vaultkeeper, the company password
manager; never reuse a work password elsewhere. Access to production systems requires a hardware
security key as the second factor.

## Phishing

Report suspicious email with the Report button in the mail client. It forwards the message to
the security team and removes it from your inbox.

## Lost devices

Report a lost or stolen laptop or phone to IT within one hour, so it can be wiped remotely.

## Data classification

Data is classified as Public, Internal, Confidential or Restricted. Restricted data, such as
customer measurement data under contract, may only be stored on approved systems.
